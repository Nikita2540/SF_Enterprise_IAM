# SF_Enterprise_IAM
This is an enterprise application for Identity and Access management of an organisation as a demonstration.

## Project Overview
This project simulates an enterprise-level Identity & Access Management (IAM) solution built on Salesforce.
It focuses on secure access provisioning, role-based permissions, approval workflows, and auditability,
similar to large multi-cloud Salesforce implementations.

## Business Problem
In large enterprises, managing user access across multiple Salesforce clouds requires:
- Strict security controls
- Approval-based access
- Audit tracking
- Separation of duties

This project addresses these challenges using Salesforce Admin capabilities.

## Personas
- Salesforce Admin
- Security Admin
- Line Manager
- End User
- Auditor

## Salesforce Org Type
- Developer Edition
- Limited licenses (simulated enterprise constraints)

## Project Scope
- Custom objects for access management
- Role-based security model
- Approval-driven access provisioning
- Automation using flows
- Reports & dashboards for audit and compliance
